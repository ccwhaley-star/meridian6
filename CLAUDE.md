## Entity optimization — the foundation of every local-SEO engagement

Core doctrine (per Chris, Oct 2026): **entity optimization is making sure
Google fully understands who a business is, what it does, where it operates,
and that its information is consistent across the entire web.** Every client
site and every SEO/AEO task should be checked against these signals:

| Signal | What it does |
|---|---|
| **Google Business Profile** | The primary entity signal — set up first, keep NAP canonical here |
| **Website** | On-page entity optimization: schema, content, NAP in footer |
| **Structured data** | JSON-LD (LocalBusiness + specific type) tells Google exactly what the business is |
| **Consistent NAP** | Name, Address, Phone identical everywhere — site, GBP, schema, citations |
| **Citations / directories** | Consistent NAP across trusted sources (Yelp, Bing, Apple, etc.) |
| **Social profiles** | Brand authority and entity recognition; link via schema `sameAs` |
| **Reviews** | Real customer signals validate the entity — review-generation flow per client |
| **PR / media mentions** | Strengthens entity relevance and trust |
| **Industry listings** | Niche directories and associations |
| **Backlinks** | Authoritative links reinforce the entity |

Payoff: higher map rankings, more visibility, more credibility, more calls
and jobs. This is why NAP must match the footer/schema **exactly** before any
site launches, why every site ships complete LocalBusiness JSON-LD, and why
GBP setup is a P1 item on every engagement.
